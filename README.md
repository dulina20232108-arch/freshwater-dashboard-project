# Agricultural Land Use and Freshwater Withdrawal Dashboard

This Streamlit dashboard analyses the relationship between cultivated land area and total freshwater withdrawal across countries.

## Dataset
The project uses two approved World Bank datasets:
- Total Freshwater Withdrawal
- Percentage of Total Country Area Cultivated

## Features
- Interactive year filter
- Country selection
- Freshwater withdrawal category filter
- Cultivation category filter
- Global map
- Scatter plot analysis
- Water use efficiency chart
- Country trend analysis
- Top 10 ranking charts

## Tools Used
- Python
- Pandas
- Plotly
- Streamlit
